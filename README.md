# Farmer Sales Platform - Frontend (Angular)

This is the frontend application for the Farmer Sales Platform, built with Angular 19.

## Requirements
- Node.js (v18+)
- Angular CLI

## Setup & Run
1. Run `npm install` to install dependencies.
2. Ensure the backend Spring Boot server is running.
3. Check `src/environments/environment.ts` to make sure it points to the correct backend URL.
4. Run `ng serve` to start the development server.

The app will be available at `http://localhost:4200`.
